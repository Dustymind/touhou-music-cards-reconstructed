# 数据分类规则 v1 —— 角色 `music[].附加信息` 的判定

适用对象：`data/characters/*.toml` 里每个 `music` 条目的第三项，取值只能是
`"角色曲"` / `"道中曲"` / `"更多道中曲"` / `"秘封曲"` 之一。

本文件是**权威规则**，由它派生 `data/meta/roles.tsv`、分类报告与校验器断言。任何实现（迁移脚本、校验器、复核表）都必须与本文件一致。

---

## 0. 权威来源

**`附加信息` 由 THBWiki Music Room 的曲目类别标签映射得到**，不由"从曲名/规则猜"得到。

- 数据源：THBWiki（`thbwiki.cc`）各作品的 Music Room 页；机器读取使用其 Markdown 镜像
  `Delsin-Yu/THBWiki-Markdown` 的 `sources/<作品>-Music.md`。
- 本地快照：`.ref/thbwiki/*.md`（21 部作品，492 行）+ `.ref/thbwiki/rows.json`（解析结果）。
  重新抓取与解析脚本见 `.ref/scripts/`（M1 会把它固化成 `tools/src/tmc/fetch_roles.py`）。
- 已覆盖 21 部作品：TH06–TH19 正作 + TH07.5 / TH10.5 / TH12.3 / TH13.5 / TH14.5 / TH15.5 / TH17.5 格斗作。
  TH20（東方錦上京 ～ Fossilized Wonders）没有进入 Markdown 镜像，抓取时**自动回落到线上页**
  `https://thbwiki.cc/<作品>/Music`（两者表格同构，解析器通用）。

THBWiki 标签的词汇（实测）：

| 标签形态 | 示例 | 含义 |
|---|---|---|
| `N面主题曲` / `第N面主题曲` | `2面主题曲` | 第 N 面**道中** BGM |
| `最终面主题曲` | `最终面主题曲` | 最终面道中 BGM |
| `Extra面主题曲` / `Phantasm面主题曲` | `Phantasm面主题曲` | Extra / Phantasm 面道中 BGM |
| `N面BOSS <角色> 主题曲` / `… 角色曲` | `2面BOSS琪露诺主题曲` | 该角色在该作品的**本人主题曲** |
| `<角色>的主题曲`（格斗作 / 花映塚 / 兽王园） | `魂魄妖梦的主题曲` | 同上 |
| `VS<角色><场景>场景用曲`（绯想天 / 非想天则） | `VS红美铃间歇泉地下中心入口` | 该角色场景的 BGM，按本人主题曲处理 |
| `<角色>角色曲<场景>`（心绮楼 / 深秘录 / 凭依华） | `秦心角色曲人类村落（夜）` | 同上 |
| `标题画面` / `对话曲` / `Ending` / `Staff画面` / `剧情曲…` / `场景用曲` / `故事模式战斗曲` / `原对话曲` | `Ending` | **不含角色**，不归属任何人 |

> 标签里"主题曲"和"角色曲"是同义词（不同作品的页面用词不同），映射时统一。

## 1. 判定规则（按顺序求值，第一条命中者胜）

| 规则 | 条件 | 结果 |
|---|---|---|
| **R-OVR** | `data/meta/extra-overrides.tsv` 里登记了该 `(专辑,曲目)`（人工裁定，必须带依据与来源） | 表里写明的值（优先级最高） |
| **R0** | 专辑 `kind == "hifuu"`（12 张秘封倶楽部 CD） | `秘封曲` |
| **R1** | 该曲在该专辑所属作品里的标签含**具体角色**（`N面BOSS <角色> 主题曲/角色曲`、`<角色>的主题曲`、`VS<角色>…场景用曲`、`<角色>角色曲<场景>`）且该角色 == 本条目的角色 | `角色曲` |
| **R2** | 标签是"面主题曲"类（道中 BGM），且**该作品 == 该角色的首发作品**，且该角色是该面的 BOSS 或中 BOSS | `道中曲` |
| **R3** | 同 R2，但**该作品 ≠ 该角色的首发作品** | `更多道中曲` |
| **R4** | 标签不含角色（标题/对话/Ending/Staff/剧情/场景/系统曲） | **不归属任何角色** → `data/meta/unowned-tracks.tsv` |
| **R5** | 格斗 / arrange 碟：标签含 `<角色>` → `角色曲`；纯系统曲 → 不归属 | —— |
| **R6** | 角色没有独立主题曲、只有道中曲（25 个单曲角色） | 仍按 R2/R3 判定，不跳过 |

### 1.1 规则扩充（已裁定，必须执行）

| 扩充 | 内容 | 理由 |
|---|---|---|
| **E1** | **面中 BOSS（中 BOSS）与面 BOSS 同等对待** | 约 10 个角色是中 BOSS 且只有道中曲（大妖精、小悪魔、リリーホワイト、犬走椛、因幡てゐ、上白沢慧音(EX)…）；不采纳这些曲目"无值可填" |
| **E3** | **Extra / Phantasm 关也算"面"** | 慧音(TH08 EX)、八雲藍(TH07 EX)、フランドール(TH06 EX)、洩矢諏訪子(TH10 EX)、八雲紫(TH07 Phantasm)、二ッ岩マミゾウ(TH13 EX)… |
| —— | **PC-98（TH01–TH05）计入"首发作品"** | `アリス` 首发于 TH05，因此她的 TH07 `ブクレシュティの人形師` 是 `更多道中曲` 而非 `道中曲` |

### 1.2 E2「一格两用」已撤销（v1 起不再存在该规则）

曾有提案：某些曲目"既是某面道中 BGM、又是该面 BOSS 主题曲"，需要一条 tie-break 规则。**该前提不成立**。

- 反例核实：`クリスタライズシルバー`（TH07，`th07_03`）在 THBWiki 上的标签是「**1面BOSS 蕾蒂·霍瓦特洛克 角色曲**」；
  TH07 第 1 面的道中曲是 `無何有の郷 ～ Deep Mountain`（`th07_02`）。前者**不是**道中曲。
- 全量检查：THBWiki 21 部作品、492 条标签中，**同一作品内同时带"面主题曲"与"角色曲"标签的曲目 = 0 条**。
  7 组"同名多标签"全部是同一类别的重复（WAV / MIDI 两版）或 `曲名不詳` 的对话曲。
- 因此 `附加信息` 对每个 `(角色, 专辑, 曲目)` 都是**唯一确定**的，不存在取舍。

## 2. 必须按 `(角色, 专辑, 曲目)` 逐条判定（不能按曲名一刀切）

> **硬前提：不同作品 / 不同 CD 上完全同名的曲目，基本都是不同的曲子。**
> 曲名**不是**身份，`(专辑, 曲目)` 才是。数据里当前有 **45 个曲名出现在 ≥2 张专辑**；
> 更极端的是同一张专辑内也有同名不同曲：`核熱造神ヒソウテンソク ～ 東方非想天則` 的
> `08. アンノウンＸ ～ Unfound Adventure` 与 `18. アンノウンＸ ～ Unfound Adventure` 音频不同，
> 只靠曲目序号区分 —— 这也是 `曲目` 必须保留 `NN. ` 的原因（校验报告里有这条依据）。
>
> 因此：**任何按曲名合并、去重、建索引、匹配的行为都是 bug**。工程侧的保证方式：
> 曲目身份统一用 `(专辑, 曲目)`（前端 `trackId = 专辑 + "\u0001" + 曲目`，后端查表同键），
> 曲名只在显示时出现；跨专辑的同名曲目在不同"作品级"标签表里分别查，互不影响。

同名曲目在不同作品里扮演不同角色的例子：

| 曲目 | 在作品 A | 在作品 B |
|---|---|---|
| `東方妖々夢 ～ Ancient Temple` | TH07：5 面主题曲（道中） | TH09：魂魄妖夢的主题曲（角色曲） |
| `春の湊に` | TH12：1 面主题曲（道中） | TH19：娜兹玲角色曲 |
| `ヴワル魔法図書館` | TH06：4 面主题曲（道中） | TH07.5：帕秋莉的夜晚主题曲（角色曲） |
| `無何有の郷 ～ Deep Mountain` | TH07：1 面主题曲 → 对 `レティ`（首发 TH07）是 `道中曲` | 同一首对 `チルノ`（首发 TH06）是 `更多道中曲` |

因此 `附加信息` **存在角色档案里**，不是曲目的全局属性；同一条 `(专辑, 曲目)` 出现在不同角色名下时可以有不同的 `附加信息`。

## 3. 不归属任何角色的曲目

判为 R4 / R5 系统曲的条目（`プレイヤーズスコア`、各作标题/对话/Ending/Staff 曲、`曲名不詳`、
格斗作的 `故事模式战斗曲` / `原对话曲` / 场景系统曲等）：

- **不**写进任何角色的 `music`；
- 写进 `data/meta/unowned-tracks.tsv`（`专辑` / `曲目` / `标签` / `理由` / `来源`）；
- 源表（`data/sources/*.json`）**照旧保留**这些条目（它们是上游已有的 URL 库存）；
- 界面提供只读的"未归属曲目"清单（配置页折叠区），不参与选曲。

## 4.1 M1 实测补充（实现口径）

- **源表拼写统一**：源表若用了旧写法（U+FF5E `～` 与 U+301C `〜`），迁移时**统一回角色数据的拼写**
  （等价键折叠后取角色数据那一边）。"两张表差一个字符"的失配因此在结构上不会出现。
- **R2/R3 的面次尚未校验**：当前口径是"标签为面主题曲 + 作品 == 首发作品"，**没有**核对这一面是否真的
  属于该角色（中 BOSS 没有主题曲标签）。`reports/stage-check.tsv` 输出 90 条道中曲/更多道中曲的对拍结果
  （match 50 / no-own-theme 26 / MISMATCH 14），M2 逐条裁决。
- **两类标签缺口**（M2 处理）：
  1. TH20（東方錦上京）没有 Music Room 页 → 14 条按 `角色曲` 占位，正式发售后复核；
  2. `東方三月精`（漫画付録 CD）无作品页 → 3 条按 R5 人工判定，已用 THBWiki 的 CD 解说页确认
     三首分别是桑尼米尔克 / 露娜切露德 / 斯塔萨菲雅的"主题曲"，写进覆盖表。
- **同一曲在同一作品有多个标签时**的优先级：面主题曲 > 角色标签 > 系统标签（系统标签只在没有前两者时生效，
  避免"面主题曲 + 剧情曲"并存时被判成不归属）。

## 5. 校验器必须断言的不变量

1. 每个 `music` 条目的第三项 ∈ {`角色曲`, `道中曲`, `更多道中曲`, `秘封曲`}。
2. `秘封曲` ⇔ 专辑 `kind == "hifuu"`（双向）。任何 `hifuu` 专辑上的曲目不得是其它三类。
3. 同一 `(角色, 专辑, 曲目)` 不重复。
4. 每条非 `秘封曲` 的 `附加信息` 必须能追溯到 `data/meta/roles.tsv` 的一行标签，或 `reports/` 里的例外登记（含理由）。
5. 同一 `(专辑, 曲目)` 若出现在多个角色名下，其 `附加信息` 可以不同（合法），但必须在报告里列出以便复核。
6. 不归属曲目不得出现在任何角色文件里，且必须出现在 `unowned-tracks.tsv`。
7. TH20（東方錦上京）的条目必须带 `待复核` 标记。
