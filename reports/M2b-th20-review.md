## 2. 判定链复现

```
R0 秘封优先        → TH20 不在 12 张秘封碟里，不适用
R1 本人主题曲      → 标签含「N面BOSS<角色>角色曲」→ 角色曲（7 条）
R2 首发作品道中曲  → 标签为「N面/Extra面主题曲」且 TH20 = 首发 → 道中曲（7 条）
E1/E3             → 面中 BOSS 与面 BOSS 同等；Extra 面也算"面"
```

本轮可以一并做（见 §4 第 3 项）。

## 4. 需要你确认的 4 件事

1. **14 条判定是否认可**（可整表确认，也可以指出哪条要改）。特别是第 2、4、6、8、9、11、13 条这 7 条
   "面主题曲 → 该面 BOSS 的 `道中曲`"的口径，以及第 9 条（Extra 面）与第 8+9 条（同一角色两条道中曲）。

   `渡里ニナ` 补 `渡里贝子`（THBWiki 译名，我们只有"渡里妮娜"）。补上后搜索与自动核对都更顺。
3. **是否生成 `data/meta/unowned-tracks.tsv`**：把全库"无角色归属"的系统曲（各作标题/Ending/Staff/剧情曲等，
   目前只出现在源表里的那些）显式登记成清单，供界面只读展示。TH20 这 4 行不在源表里，因此不会出现在其中。
4. **是否解除 TH20 的"待复核"标记**：`docs/rules-classification-v1.md` §6 里写着"TH20 待正式发售后复核"，

## 5. 复现命令

```bash
cd tools && UV_CACHE_DIR=.uv/cache uv run python -m tmc.fetch_roles --parse   # 只解析本地已抓取页
python3 - <<'PY'   # 归一化对照（上表就是它的输出）
import json, tomllib, pathlib, sys
sys.path.insert(0, "tools/src"); from tmc import repo
rows = json.load(open(".ref/thbwiki/rows.json"))["东方锦上京"]
index = {repo.lookup_key(t): l for l, t in rows}
for p in sorted(pathlib.Path("data/characters").glob("*.toml")):
    c = tomllib.load(open(p, "rb"))
    for album, title, extra in c["music"]:
        if "錦上京" in album:
            print(c["name"], title, extra, "->", index.get(repo.lookup_key(title), "找不到"))
PY
```
