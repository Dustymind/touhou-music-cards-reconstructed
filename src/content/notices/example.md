## 一、行内标记

这一行演示**粗体**、*斜体*、还有 `行内代码`，三者可以按任意顺序混在同一行里。

### 二、列表

无序列表（`-`、`*`、`+` 都认）：

- 第一项：纯文本
- 第二项：**粗体** 与 *斜体* 与 `code`
- 第三项：一个[外部链接](https://github.com/Dustymind/touhou-music-cards-reconstructed)

列表项之间**紧挨着写**（中间不空行）就是一个列表；中间夹空行在 CommonMark 里仍是**同一个**列表
（`loose`），只是每项变成独立段落 —— 观感上仍是同一个 `<ul>`，不用特意回避空行。

⚠️ 但**普通项与任务项相邻**时会被切成两个列表（见下节），因为两者的渲染方式不同。

有序列表（`1.` 与 `2)` 都认，序号只用来识别，渲染时从 1 重新编）：

1. 第一步
2. 第二步
3. 第三步

### 三、任务列表

任务项用 `- [ ]` / `- [x]` 开头，渲染成**只读**复选框；勾上的那项会加删除线（公告里没有交互语义）：

- [x] 已经做完的事
- [ ] 还没做的事
- [ ] 也是待办

### 四、引用、代码与表格

引用块（`>`）里可以再放**完整的块级语法**：

> 引用里的第一段。
>
> - 引用里的列表
> - 第二项
>
> ```sh
> # 引用里的代码块
> pnpm dev
> ```

围栏代码块（也可用 4 空格缩进），空白**原样保留**：

```ts
// 语言的标记只是标记，不做高亮
const greeting = "你好";
function hi(name: string): string {
  return `${greeting}，${name}`;
}
```

GFM 表格（`|` 分隔，第二行的 `:--` / `:-:` / `--:` 控制对齐）：

| 列名 | 居中列 | 右对齐列 |
| :-- | :-: | --: |
| 左对齐 | 居中 | 123 |
| 太长的话会自己折行 | 也可以 | 456 |

### 五、删除线与图片

删除线 `~~删掉~~` 渲染成 ~~删掉~~。

图片只认 http / https（与链接同一套白名单），`![替代文字](https://example.com/i.png)` 会渲染成一张图；
写了 `javascript:` 之类的地址就**原样显示成文字**，不会变成 `<img>`。

### 六、换行与语言

硬换行靠在**行尾留两个空格**：
这一行末尾有两个空格  
所以它与下一行之间会被强制断行，而不是折成同一段。

中文与 English 可以混排（mixed text renders the same in both en / zh UIs）——
正文**只有一份**、不按语言分：界面右上角切语言时，这段字是不变的。
